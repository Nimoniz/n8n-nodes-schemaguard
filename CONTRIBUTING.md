# Contributing

Thanks for considering a contribution to SchemaGuard.

## Local development

```bash
npm install
npm run build
npm test
npm run lint
npm run dev
```

## Pull requests

- Keep changes focused.
- Add or update tests for behavior changes.
- Avoid sending workflow payloads to external services.
- Preserve backward-compatible defaults where possible.

## Bug reports

Please include:

- n8n version
- Node.js version
- SchemaGuard version
- minimal input example
- expected behavior
- actual behavior
